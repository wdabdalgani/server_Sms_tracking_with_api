١ — الهدف

الكود يمثل عميل HTTP يرسل POST بجسم JSON إلى api/send.php على سيرفر مشروعك، مع ترويسة X-API-Key لمطابقة api.key في config.php. بعدها يطبع JSON يجمع رمز HTTP من الوسيط مع جسم الرد ليسهل قراءته من متصفح أو من نظام خلفي.

٢ — المتطلبات

  • PHP مع امتداد curl.
  • وصول شبكي من السيرفر الذي يشغّل العميل إلى عنوان api/send.php.
  • على سيرفر sm: api.key غير فارغ؛ وقاعدة البيانات مثبتة (install_db.php).
  • بيانات السحابة: إما في JSON (cloud_*) أو في config.php → cloud.

٣ — القالب الكامل (عناصر نائبة)

<?php
declare(strict_types=1);

$apiUrl = 'https://your-domain/sm/api/send.php';
$apiKey = 'YOUR_API_KEY';

$payload = [
    'phone_number'   => '+966500000000',
    'message'        => 'نص الرسالة',
    'cloud_api_url'  => 'https://api.sms-gate.app/3rdparty/v1/message',
    'cloud_username' => 'CLOUD_USER',
    'cloud_password' => 'CLOUD_PASS',
];

$ch = curl_init($apiUrl);
curl_setopt_array($ch, [
    CURLOPT_POST           => true,
    CURLOPT_POSTFIELDS     => json_encode($payload, JSON_UNESCAPED_UNICODE),
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER     => [
        'Content-Type: application/json; charset=utf-8',
        'X-API-Key: ' . $apiKey,
    ],
    CURLOPT_TIMEOUT        => 45,
]);

$raw   = curl_exec($ch);
$errno = curl_errno($ch);
$err   = $errno ? curl_error($ch) : '';
$http  = (int) curl_getinfo($ch, CURLINFO_HTTP_CODE);
curl_close($ch);

header('Content-Type: application/json; charset=utf-8');
if ($errno !== 0) {
    echo json_encode(['ok' => false, 'curl_error' => $err], JSON_UNESCAPED_UNICODE);
    exit;
}

$decoded = json_decode((string) $raw, true);
echo json_encode(
    [
        'http_status_from_sm' => $http,
        'body'                => is_array($decoded) ? $decoded : $raw,
    ],
    JSON_UNESCAPED_UNICODE | JSON_PRETTY_PRINT
);

٥ — حقول JSON (مرتبطة بـ api/send.php)

أساسية

  • phone_number أو phone
  • phoneNumbers — قائمة (سحابة)
  • message

اختيارية

  • gateway_* — إرسال محلي
  • cloud_* — سحابة مع الطلب

٦ — الرد من الوسيط

عند HTTP 200 غالباً: success، log_id، inbox_id، delivered، http_code، gateway_response، … راقب delivered لأن success: true لا يضمن تسليم المزوّد.

التفاصيل الكاملة للحقول والأمثلة: api-demo.html
